# Porsche Car Configurator (Клиентский конфигуратор автомобилей)

[![GitHub Pages](https://img.shields.io/badge/Demo-GitHub%20Pages-d5001c?style=for-the-badge&logo=github)](https://whoami-28.github.io/auto-config/)
[![Stack](https://img.shields.io/badge/Stack-HTML5%20%7C%20CSS3%20%7C%20Vanilla%20JS%20(ES6+)-black?style=for-the-badge)](https://developer.mozilla.org/ru/docs/Web/JavaScript)
[![License](https://img.shields.io/badge/License-MIT-lightgrey?style=for-the-badge)](LICENSE)

Интерактивный клиентский сервис для индивидуальной комплектации спортивных автомобилей, разработанный в стиле и по UX/UI принципам официального конфигуратора **Porsche Car Configurator**.

Проект реализован **строго на нативном стеке: HTML5, CSS3, JavaScript (ES6+ Modules)** без использования сторонних фреймворков и без серверного бэкенда.

## 🚀 Ключевые возможности и функционал

### 1. Интерактивный фотореалистичный визуализатор (Vehicle Visualizer)
- **4 студийных ракурса высокой четкости**:
  - `3/4 Спереди`: каноничный передний ракурс экстерьера.
  - `Профиль`: чистый аэродинамический силуэт автомобиля.
  - `3/4 Сзади`: демонстрация широких крыльев, сплошной светодиодной полосы фонарей (LED Lightbar) и спортивного выхлопа.
  - `Салон (Кокпит)`: детальный вид водительского места со спортивным рулем GT Sport, приборной панелью, экраном PCM и секундомером Sport Chrono.
- **Динамическая смена цвета кузова**: при выборе оттенка кузова (Guards Red, Shark Blue, Crayon / Chalk, GT Silver Metallic, Jet Black, Racing Yellow) визуализатор переключает фоторендер на выбранную эмаль.
- **Ночной режим освещения (Night Mode)**: включение 4-точечной матричной оптики LED Matrix с эффектными направленными световыми лучами и ночной студийной атмосферой.
- **Полноэкранный режим** и **скачивание фотографии текущего ракурса** в высоком разрешении.

### 2. Динамический расчет стоимости в реальном времени (Pricing Engine)
- Расчет по формуле Porsche MSRP:
  $$\text{Total MSRP} = \text{Base MSRP (Комплектация)} + \text{Оборудование и опции} + \text{Delivery Fee (Транспортировка)}$$
- **Мгновенный реактивный пересчет**: любые изменения в комплектации, цвете, дисках, салоне или опциях мгновенно обновляют ценники в верхнем фиксированном хедере, карточках каталога и нижнем sticky-баре.
- **Мультивалютность**: переключение валют **RUB (₽)**, **USD ($)**, **EUR (€)** с автопересчетом по курсу.
- **Информационное окно детализации стоимости**: клик на кнопку «Детализация цены ⓘ» открывает модальное окно с подробной разбивкой по каждому выбранному компоненту.

### 3. Полный пошаговый маршрут конфигурации (User Journey)
1. **Этап 1: Модель (Model Catalog)**:
   - Выбор линейки: *Porsche 911*, *Porsche Taycan*, *Porsche Panamera*, *Porsche 718 Cayman*.
   - Карточки моделей с техническими benchmark-показателями (мощность, разгон 0-100 км/ч, максимальная скорость).
2. **Этап 2: Комплектация и силовая установка (Trims & Engines)**:
   - Модификации для 911: *Carrera*, *Carrera S*, *Carrera GTS T-Hybrid*, *Turbo S*, *GT3 RS*.
   - Детализация двигателей (Boxer Biturbo, T-Hybrid, высокооборотистый атмосферный 4.0L) и КПП (8-PDK / 7-МКПП).
3. **Этап 3: Экстерьер (Colors & Wheels)**:
   - Палитра цветов по категориям: *Contrasts* ($0), *Shades* (металлики), *Dreams* (спортивные эмали), *Paint to Sample* (исторические цвета мануфактуры).
   - Выбор колесных дисков: 19/20" Carrera, 20/21" Carrera S, 20/21" RS Spyder Design, 20/21" Turbo Exclusive с карбоновыми Aeroblades, 20/21" кованые Center-Lock с центральной гайкой.
   - Окраска дисков (Brilliant Silver, Satin Black, Neodyme, Darksilver).
   - Тормозные суппорты (черные, красные Porsche Red, желтые PCCB Ceramic).
4. **Этап 4: Интерьер и сиденья (Interior & Seats)**:
   - Материалы: Стандартная отделка, Натуральная кожа, Двухцветная кожа Bordeaux Red, Клубная кожа Olea Truffle Brown, Спортивный микрофибровый Race-Tex.
   - Сиденья: Спортивные 4-позиционные, Спортивные с памятью (14 позиций), Адаптивные Sports Seats Plus (18 позиций), Облегченные карбоновые ковши (Full Bucket Seats).
5. **Этап 5: Опции и пакеты (Equipment & Packages)**:
   - Полнотекстовый живой поиск по названию или заводскому PR-коду (PCCB, Chrono, 4D3, BOSE и т.д.) с подсчетом совпадений.
   - Индивидуальные опции: Sport Chrono, выхлопная система Sport Exhaust, керамические тормоза PCCB, лифт передней оси Front Axle Lift, матричные фары PDLS Plus, карбоновая крыша, аудиосистемы BOSE и Burmester High-End, автопилот InnoDrive, ночное видение Night Vision.
6. **Этап 6: Итог (Summary Screen)**:
   - Фотография итогового автомобиля в выбранном цвете.
   - Построчная спецификация с ценами и PR-кодами.
   - **Возможность изменения любого элемента до завершения выбора**: кнопки «Изменить ✎» мгновенно переносят пользователя к нужному этапу для корректировки.
   - Прямое удаление дополнительных опций кнопкой «✕» прямо из таблицы спецификации.
   - Генерация уникального **Porsche Code** (например, `PR-911-GTS-4K9L1A`).
   - Копирование кода и ссылки для шеринга.
   - Сохранение/загрузка конфигурации через экспорт/импорт **JSON**.
   - Печать и экспорт в **PDF** через встроенный print-стиль дилерской брошюры.

### 4. Интеллектуальный движок ограничений и совместимости (Feasibility Engine)
Реализована строгая система правил совместимости автомобильного оборудования с информированием пользователя о причинах ограничений:

- **Правило 1 (Карбоновые ковши vs Вентиляция сидений)**:
  - *Ограничение*: опция «Вентиляция сидений» несовместима с облегченными карбоновыми ковшами (Full Bucket Seats), так как монокок ковшей не содержит вентиляционных каналов.
  - *Диалог разрешения (Feasibility Modal)*: информирует о конфликте, предлагает автоматическую замену ковшей на комфортные сиденья с электрорегулировками (14 позиций) и рассчитывает итоговую финансовую дельту.
- **Правило 2 (Тормоза PCCB и диаметр дисков)**:
  - *Ограничение*: керамические тормозные диски PCCB имеют диаметр 410 мм и физически не помещаются в базовые 19/20-дюймовые диски.
  - *Разрешение*: автообновление дисков до 20/21" Carrera S и суппортов до желтых PCCB.
- **Правило 3 (Карбоновая крыша vs Панорамный люк)**:
  - *Ограничение*: взаимоисключающие опции конструкции крыши. Выбор одной опции заменяет другую.
- **Правило 4 (Акустика Burmester® vs BOSE®)**:
  - *Ограничение*: взаимоисключающие аудиокомплексы.
- **Правило 5 (Система подъема передней оси)**:
  - *Ограничение*: Front Axle Lift требует обязательной установки пакета Sport Chrono для интеграции с датчиками ускорения.
- **Правило 6 (Диски Center-Lock с центральной гайкой)**:
  - *Ограничение*: требуют специальные гоночные ступицы, доступные только на модификациях GTS, Turbo S и GT3 RS.
- **Информирование прямо в каталоге**: карточки несовместимых опций содержат предупреждающие бейджи `⚠️` с четким описанием технической причины до клика.

## 🛠 Технологический стек и архитектура

- **HTML5**: Семантическая разметка, доступность, модальные диалоги.
- **CSS3**:
  - Porsche Design System (темная премиальная эстетика, шрифты Inter и Montserrat).
  - Flexbox и Grid Layout для асимметричного Split-Screen экрана.
  - Адаптивный дизайн (десктопы, планшеты, смартфоны).
  - Стилизация для печати (`@media print`) — формирование чистого белого буклета для передачи дилеру.
- **JavaScript (ES6+ Modules)**:
  - `js/data.js` — Каталог данных: модели, двигатели, цвета, диски, интерьеры, сиденья, опции и правила совместимости.
  - `js/engine.js` — Реактивный State Management (паттерн Observer), расчет цен, движок проверки зависимостей и генератор Porsche Code.
  - `js/visualizer.js` — Управление фотовизуализатором, ракурсами камеры, ночным режимом и сменой цветов.
  - `js/app.js` — Контроллер пользовательского интерфейса, навигация, поиск опций, модальные окна и экспорт.

## 💻 Локальный запуск

Так как проект использует нативные ES6 JavaScript модули (`import` / `export`), для локального просмотра требуется запустить любой статический HTTP-сервер:

### Способ 1: С помощью Python (установлен почти везде)
```bash
# В папке проекта CarConfig:
python -m http.server 8080
```
Затем откройте в браузере: [http://localhost:8080](http://localhost:8080)

### Способ 2: С помощью Node.js
```bash
npx serve .
```

### Способ 3: С помощью расширения Live Server для VS Code
Кликните правой кнопкой мыши по `index.html` и выберите **«Open with Live Server»**.

## 🚢 Деплой на GitHub Pages

Проект настроен для мгновенного развертывания:
1. В репозитории уже настроен GitHub Actions workflow (`.github/workflows/deploy.yml`).
2. В настройках репозитория на GitHub перейдите в **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите:
   - **GitHub Actions** (для автоматического деплоя через workflow), либо
   - **Deploy from a branch** → ветка `main` / `root`.
4. Сервис будет доступен по адресу: `https://<username>.github.io/<repo-name>/`.
