# Porsche Car Configurator (Конфигуратор автомобилей Porsche)

[![GitHub Pages](https://img.shields.io/badge/Demo-GitHub%20Pages-black?style=for-the-badge&logo=github)](https://whoami-28.github.io/auto-config/)
[![Node.js](https://img.shields.io/badge/Backend-Node.js%20%7C%20Express-339933?style=for-the-badge&logo=node.js)](https://nodejs.org/)
[![Frontend](https://img.shields.io/badge/Frontend-HTML5%20%7C%20CSS3%20%7C%20Vanilla%20ES6-black?style=for-the-badge)](https://developer.mozilla.org/ru/docs/Web/JavaScript)
[![License](https://img.shields.io/badge/License-MIT-lightgrey?style=for-the-badge)](LICENSE)

Премиальный сервис индивидуальной комплектации спортивных автомобилей в строгом минималистичном стиле: монохромная гамма оттенков черного и глубокого серого, мягкие тени, простые геометрические формы и полное отсутствие визуального мусора.

Сервис поддерживает работу в двух режимах:
- **Full-stack режим с Node.js бэкендом**: серверный REST API для валидации опций, расчета стоимости и постоянного сохранения сборок по Porsche Code.
- **Статический режим (GitHub Pages)**: клиентская валидация и генерация кодов в браузере при автономной работе.

## Архитектура и возможности

### 1. Минималистичный премиальный дизайн
- **Цветовая палитра**: глубокий графитовый фон (`#09090b`), многоуровневые серые поверхности (`#121215`, `#18181b`), сверхтонкие границы (`rgba(255, 255, 255, 0.08)`), мягкие рассеянные тени (`box-shadow: 0 16px 40px rgba(0, 0, 0, 0.65)`).
- **Сдержанная типографика**: высококлассные шрифты *Inter* и *Montserrat*, чистые геометрические формы кнопок и переключателей.
- **Zero-Icon Noise**: полное отсутствие эмодзи и кричащих декоративных значков — только строгие метки и функциональные индикаторы.

### 2. Фотореалистичный визуализатор (Vehicle Visualizer)
- **4 студийных ракурса высокой четкости**:
  - `3/4 Спереди`: каноничный передний ракурс экстерьера.
  - `Профиль`: чистый аэродинамический силуэт автомобиля.
  - `3/4 Сзади`: сплошная полоса задних светодиодных фонарей и аэродинамический диффузор.
  - `Салон`: спортивный кокпит с рулем GT Sport, экранами PCM и аналоговым секундомером.
- **Динамическая смена цвета кузова**: фоторендеры эмалей Guards Red, Shark Blue, Chalk/Crayon, GT Silver, Jet Black, Racing Yellow.
- **Ночной режим (Night Mode)**: включение 4-точечных матричных фар LED Matrix со студийным ночным освещением.
- **Полноэкранный просмотр** и сохранение фотографий текущего ракурса в высоком разрешении.

### 3. Серверная архитектура (Node.js REST API)
Серверная часть реализована на платформе **Node.js** с использованием фреймворка **Express**:
- `GET /api/health` — проверка работоспособности сервера и аптайма.
- `GET /api/catalog` — единое дерево каталога (модели, комплектации, опции, курсы валют).
- `POST /api/config/validate` — серверная валидация совместимости выбранного пакета опций.
- `POST /api/config/save` — валидация, расчет официальной цены MSRP, генерация уникального Porsche Code и сохранение в файловую базу данных `server/data/configurations.json`.
- `GET /api/config/:code` — загрузка сохраненной сборки по Porsche Code.
- `GET /api/configs` — список последних сохраненных сборок.

### 4. Интеллектуальный движок ограничений и совместимости (Feasibility Engine)
Строгая проверка зависимостей и несовместимостей оборудования как на клиенте, так и на сервере:
1. **Карбоновые ковши vs Вентиляция сидений**:
   - Облегченные ковши Full Bucket не содержат внутренних вентиляционных каналов.
   - Диалог авторазрешения предлагает комфортные 14-позиционные кресла с памятью и вычисляет разницу в стоимости.
2. **Керамические тормоза PCCB и колесные диски**:
   - Массивные 410-мм диски PCCB требуют колесные диски не менее 20/21 дюйма.
3. **Карбоновая крыша vs Стеклянный люк**:
   - Взаимоисключающие конструкции крыши кузова.
4. **Акустика Burmester High-End vs BOSE Surround**:
   - Взаимоисключающие премиальные аудиосистемы.
5. **Система подъема передней оси (Front Axle Lift)**:
   - Требует обязательной установки пакета Sport Chrono.
6. **Диски Center-Lock с центральной моногайкой**:
   - Доступны только для модификаций GTS, Turbo S и GT3 RS.

### 5. Пошаговый конфигуратор (User Steps)
1. **Модель**: выбор между 911, Taycan, Panamera и 718 Cayman.
2. **Комплектация**: выбор силовой установки, мощности и трансмиссии (Base, S, GTS, Turbo S, GT3 RS).
3. **Экстерьер**: подбор эмали кузова, дисков, финиша дисков и цвета тормозных суппортов.
4. **Интерьер**: выбор натуральной кожи, двухцветной отделки, Race-Tex и конструкции сидений.
5. **Опции и пакеты**: поиск по PR-коду или названию, категории динамики, комфорта и мультимедиа.
6. **Итог**: полная спецификация с возможностью быстрого изменения любого параметра или удаления опции, печать буклета и генерация кода сборки.

## Запуск проекта

### Вариант 1: Запуск с Node.js сервером (Рекомендуется)

1. Установите зависимости проекта:
   ```bash
   npm install
   ```

2. Запустите сервер:
   ```bash
   npm start
   ```

3. Откройте в браузере:
   ```text
   http://localhost:3000
   ```

Сервер автоматически раздает статические файлы фронтенда и обслуживает все REST API запросы по адресу `/api/*`.

---

### Вариант 2: Запуск без бэкенда (Любой статический сервер)

Благодаря архитектуре с graceful degradation клиент автоматически использует встроенный расчет и локальную генерацию Porsche Code:

```bash
# С помощью Python:
python -m http.server 8080

# С помощью npx serve:
npx serve .
```
